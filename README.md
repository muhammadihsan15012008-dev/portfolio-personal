# Portfolio Personal

Website portofolio personal yang dibuat dengan HTML5 dan CSS3 (tanpa backend).

## Bagian website
Beranda, Tentang, Keahlian, Proyek, dan Kontak.

## Cara menjalankan
Buka file `index.html` langsung di browser, atau gunakan GitHub Pages (Settings > Pages > Branch `main`).

## Struktur
```text
portfolio-personal/
├── index.html
├── style.css
├── images/profile.jpg
├── screenshots/
└── README.md
```
